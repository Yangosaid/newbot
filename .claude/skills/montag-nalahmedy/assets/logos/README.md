# أيقونات وشعارات التطبيقات

## `apps/` — أيقونات جاهزة للفيديو (استخدمها أول)
PNG مربع 512px بزوايا دائرية، **بألوان التطبيق الأصلية**.

| المصدر | الملفات |
|---|---|
| **من نايف** (أيقونات رسمية حمّلها بنفسه) | claude، chatgpt، apple، capcut، vn، وشعارات نصية: samsung_wordmark، midjourney_wordmark، gemini_wordmark |
| **Simple Icons** (CC0، بلون العلامة على خلفية بيضاء) | anthropic، blackmagicdesign، davinciresolve، dji، figma، google، googlegemini، instagram، meta، notion، nvidia، perplexity، snapchat، telegram، threads، tiktok، whatsapp، x، youtube |

## `*.svg` — نفس شعارات Simple Icons بلون العلامة (للاستخدام إذا تبي حجم أو خلفية مختلفة)

**ناقصة (اطلبها من المستخدم):** Adobe (Premiere/Photoshop/Lightroom)، Canva، Higgsfield، Kling، Seedance، Topaz، Blackmagic Camera، ReLens، DJI Mimo، Nano Banana.
عند إضافة أيقونة جديدة من المستخدم: قص مربع من الوسط ← 512px ← زوايا دائرية (radius 22%) ← احفظها `apps/<name>.png` (أحرف إنجليزية صغيرة وشرطة سفلية فقط).

الشعارات علامات تجارية لأصحابها؛ تُستخدم للإشارة للتطبيق في المحتوى فقط.
