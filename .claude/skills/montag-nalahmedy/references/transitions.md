# مكتبة الانتقالات

كل انتقال له `id` يستخدمه سكربت `pick_transitions.py`. المدة الافتراضية 8–14 فريم (عند 30fps). الحقل `person` يعني الانتقال يحتاج شخص بالكادر.

## أ) انتقالات Magic Mask (تحتاج شخص بالكادر)

| id | الاسم | الفكرة | المؤثر الصوتي |
|---|---|---|---|
| `mm_reveal` | كشف من ورا الشخص | المقطع الجاي يظهر **خلف** نايف، ونايف يبقى قدام لحظة ثم يختفي | whoosh ناعم |
| `mm_text_behind` | نص خلف الشخص | كلمة كبيرة (عنوان القسم) تدخل خلف نايف، ثم المقطع الجاي يمسح الشاشة | impact خفيف + whoosh |
| `mm_pop_out` | خروج من الإطار | المقطع الحالي يصغر لكرت، ونايف "يطلع" من حدود الكرت | pop + swish |
| `mm_glow_trail` | ظل نيون | حدود نايف تتوهج بنفسجي ثم تنتشر وتغطي الشاشة وتكشف المقطع الجاي | riser قصير + shimmer |
| `mm_split_bg` | انشطار الخلفية | الخلفية تنقسم نصين وتتحرك، ونايف ثابت، والمقطع الجاي يظهر بينهم | swoosh مزدوج |

### طريقة بناء Magic Mask
1. **بالـ API أولاً:** ابحث بـ `search_scripting_api` عن `MagicMask` / `CreateMagicMask` / `Track`. إذا موجود، طبّقه على كليب نايف ثم صدّر الماسك كـ Alpha للاستخدام في Fusion.
2. **البديل (ماسك خارجي):** استخرج فريمات النافذة فقط (حول التأثير، مو الفيديو كامل) بأسماء `f_0001.png`، ثم:
   ```
   python scripts/person_mask.py <مجلد_الفريمات> <مجلد_الإخراج>
   ```
   السكربت يطلع PNG بقناة Alpha بدون رجفة. استوردها في Resolve كـ Image Sequence فوق الكليب الأصلي.
3. داخل Fusion: `MediaIn (المقطع الجاي) → Merge ← (نص/خلفية) → Merge ← الشخص المفصول (Alpha)` ثم حرّك الطبقات بـ keyframes.
4. إذا فشل الاثنين: Marker أحمر باسم `MAGIC MASK: <id>` + خطوات يدوية: صفحة Color ← Magic Mask ← Person ← Track Forward ← استخدمه بـ Alpha Output.

## ب) انتقالات الحركة (بدون شخص)

| id | الاسم | الفكرة | المؤثر الصوتي |
|---|---|---|---|
| `zoom_punch` | زوم بنش | زوم سريع لداخل آخر فريم ثم يطلع المقطع الجاي من زوم معاكس + motion blur | whoosh قوي |
| `whip_pan_l` | وب بان يسار | حركة سريعة لليسار مع blur اتجاهي | swish |
| `whip_pan_up` | وب بان فوق | نفس الفكرة لفوق | swish |
| `spin_blur` | دوران | دوران 90–180° مع blur | spin whoosh |
| `glitch_rgb` | جلتش | فصل ألوان RGB وتقطيع لمدة 6 فريم | glitch |
| `light_leak` | تسريب ضوء | ضوء بنفسجي/أزرق يمسح الشاشة | shimmer |
| `shape_wipe` | مسح بشكل | دائرة أو شكل الهوية يكبر ويكشف المقطع الجاي | pop |
| `slide_stack` | انزلاق كروت | المقطع الحالي ينزلق ككرت والجاي تحته | slide |
| `flash_cut` | فلاش | فريمين أبيض/بنفسجي | camera shutter |
| `film_burn` | حرق فيلم | انتقال حرق فيلم سينمائي | film reel |
| `ink_reveal` | حبر | كشف بشكل حبر يتمدد | liquid swoosh |
| `grid_split` | شبكة | الشاشة تتقسم مربعات وتتقلب | digital tick |

## قواعد الاختيار
- **بين قسمين مختلفين بالفيديو:** انتقال قوي (Magic Mask أو `zoom_punch` أو `film_burn`).
- **داخل نفس القسم:** انتقال خفيف (`whip_pan_*`, `slide_stack`, `flash_cut`) أو قطع مباشر.
- **من الكاميرا إلى الشاشة:** `zoom_punch` أو `shape_wipe`.
- **لا تحط انتقال على كل قطع.** القطع المباشر (jump cut) ممتاز داخل الكلام؛ الانتقالات للأقسام والتحويل بين المشاهد.
