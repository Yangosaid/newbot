# ستايل "الورق المقصوص والملصقات التحريرية" (Editorial Paper)

مأخوذ من تحليل ريل مرجعي (51 ث، 9:16). القالب: `templates/EditorialKit.tsx` (المكونات) و`templates/EditorialDemo.tsx` (مثال كامل مجرّب).

**متى:** ريلز الكلام للكاميرا اللي تشرح فكرة أو أداة أو قصة (ذكاء اصطناعي، إنتاجية، صناعة محتوى). **مو** للقطات بدون كلام (B-roll) ولا للشرح الطويل على يوتيوب.

## الفكرة الأساسية
**كل جملة = استعارة بصرية لمعناها**، مو زينة. عنصر جديد كل 2–4 ثواني، والفيديو ما يقف أبداً.

| يقول | العنصر (من EditorialKit) |
|---|---|
| جملة قوية/خلاصة ("ما لمسته يدي") | `Tag` بلون التمييز، مائل بإطار أبيض |
| يذكر أداة/تطبيق | **على الفيديو نفسه** (الشخص يبقى بالكادر): `Cutout` بأيقونة التطبيق (round, w≈230) فوق + `Tag` أسود باسمها — **مو مشهد ورق** |
| "أصور نفسي" / يتكلم عن نفسه | `PaperScene` + `Cutout` صورته أبيض وأسود (bw) بشريط لاصق |
| صوت / تسجيل / سكتات | `WaveCard` (موجة + أماكن السكتات بالأحمر تنقص) |
| "يطلع الكلمات / الكابشن" | `WaveCard` مع `chips` (كل كلمة بتوقيتها) |
| "ينزل / ينشر" | `PhonePost` (زر نشر ← تم النشر ✓) |
| "وش تطلب / البرومبت" | `PromptBox` (ينكتب حرف حرف + زر إرسال) |
| قبل/بعد بالوقت ("يوم كامل" ← "دقائق") | `StrikeTag` ("8 ساعات" تنشطب) ثم `Stamp` كبير مع فلاش |
| مدة / وقت | `Clock` أو `ProgressTimer` (شريط + عداد أحمر) |
| "تابعني / تواصل معي / الخاص" | `DMCard` (اسمه + متصل الآن + رسائل) |
| البداية | `Viewfinder` (REC 00:00:00 + 4K 30) أول ثانية |

## الهوية البصرية للستايل
- **الألوان:** ورق `#F1ECE1`، أسود `#141414`، **لون التمييز برتقالي Claude `#D97757`** (نايف رفض الأحمر `#E0262B` حق المرجع — لا ترجّعه)، بيج المشاهد `#E6DED0`، أزرق واجهات `#3B82F6`. لون التمييز واحد بـ `ED.red` في `EditorialKit.tsx`: لو مستخدم ثاني يبي لونه، غيّره هناك بس.
- **الخط:** عربي عريض جداً (weight 800–900). الافتراضي `Segoe UI`؛ أو خط المستخدم العريض.
- **الكابشن (`PaperCaption`):** شريط ورق مائل ‎-1° بظل، 3 كلمات، **كلمة وحدة مهمة بمربع بلون التمييز وخط أبيض**. اختر الكلمات المهمة (`hot`) يدوياً: الأدوات، الأفعال الأساسية، الأرقام، كلمة الخلاصة.
- **الملصقات:** دايماً مائلة (‎-7° إلى +5°)، تدخل بـ spring (ارتداد)، ظل `0 10px 24px`. نوّع: لون التمييز للصدمة/الخلاصة، أسود للأسماء، ورق مع شريط لاصق للملاحظات.
- **مشاهد الورق (`PaperScene`):** تغطي الفيديو 1.5–2.5 ث، تدخل بمسحة من تحت وتطلع لفوق، ملمس ورق (feTurbulence) + فينيت. العناصر داخلها تدخل متتابعة (`delay` 3–9 فريم).
- **التلوين:** `MoodyGrade` (فينيت قوي + حبيبات فيلم). المرجع مصور بإضاءة غامقة حمراء/تيل؛ لو التصوير ساطع، خليه 0.6–0.8.
- **الكاميرا:** حركة بطيئة دائمة (scale 1.04 ± 0.02) عشان الكادر ما يكون ميت.

## قواعد مجرّبة (غلطات صارت)
- **العنصر له نهاية:** أي `Cutout`/`Tag` لازم ياخذ `to`؛ أيقونة بقت طول الفيديو لأنها بدون نهاية.
- **لا تحط عنصر بمنطقة الكابشن:** الكابشن عند `bottom: 520` (≈ y 1300–1400 على 1920). الختم والملصقات فوق (y 300–500) أو وسط المشاهد الورقية فوق 1250.
- **الكلام خلف الشخص:** بمستوى الرأس (الكلمة تبدأ ~y 470)، والرأس يغطي وسطها. الكلمة القصيرة **تُمدّ بالكشيدة** باعتدال (خـلـفـي) عشان أطرافها تبان على الجانبين — كشيدة زيادة تطلّع الحروف برا الشاشة. فوق الرأس = مو خلفه (مرفوض).
- **المؤثرات:** `whip` لدخول المشاهد الورقية، `pop` للملصقات، `heavy` للختم والكلام خلف الشخص، `chime` للنجاح (تم النشر). المستويات من `sfx_levels.py`.

- **تغيير الخلفية = إطار برتقالي حول الشخص** (`Person outline`)، بلون التمييز `#D97757`. راجع القاعدة الثابتة في `SKILL.md`.
- **ممنوع: صناديق التحديد الزرقاء (cut-1 / face-1).** موجودة بالمرجع، لكن نايف ما يبيها وانشالت من `EditorialKit`. لا ترجّعها.
- **مشاهد الورق للاستعارات بس** (أصور نفسي، النشر، المحادثة...)، **مو لذكر التطبيقات**: لما نايف قال «حط لي ChatGPT» وغطّيناه بمشهد ورق، رفضه وطلب نفس معاملة كلود.
